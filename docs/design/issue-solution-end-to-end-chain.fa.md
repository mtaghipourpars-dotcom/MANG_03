# زنجیره انتهابه‌انتهای مسئله تا راهکار — نسخه فارسی

## جریان اصلی
ثبت اولیه ← ارزیابی صلاحیت ← ایجاد/پیوند پرونده رسمی ← ایجاد گزینه‌های راهکار مختص پرونده ← بررسی امکان‌پذیری و محدودیت‌های قطعی ← مقایسه اولویت در پروفایل نسخه‌دار ← تصمیم توسط مرجع مجاز ← تعریف و اجرای اقدام ← ارزیابی نتیجه مشاهده‌شده ← پیگیری و یادگیری کنترل‌شده.

## تفکیک‌های الزامی
- ثبت اولیه، پرونده پذیرفته‌شده نیست.
- فوریت، صلاحیت و اولویت یکی نیستند.
- امکان‌پذیری قبل از رتبه‌بندی بررسی می‌شود؛ امتیاز بالا نمی‌تواند محدودیت قطعی را دور بزند.
- نوع راهکار قابل‌استفاده مجدد با گزینه مختص پرونده تفاوت دارد.
- تصمیم با اقدام، تکمیل اقدام یا حل مسئله برابر نیست.
- اثر برآوردی، نتیجه مشاهده‌شده و انتساب علّی باید جدا ثبت شوند.
- ارتباط زمینه‌ای یا تقدم زمانی، علت را اثبات نمی‌کند.

## کنترل شواهد و وضعیت نامشخص
اگر شواهد کافی نیست، مجهول را صریح نگه دارید و از توصیه خودداری کنید، هرگاه رتبه‌بندی اطمینان کاذب بسازد. مسیر اضطراری فقط برای پیشنهاد اقدام محدود، برگشت‌پذیر و دارای مسئول، انقضا و بازبینی است؛ این مسیر مجوز اجرای خودکار یا عبور از کنترل‌های ایمنی، قانونی و فنی نیست.

## نتیجه و یادگیری
نتیجه باید با هدف تثبیت‌شده در زمان تصمیم مقایسه شود. یک پرونده یا نتیجه مطلوب برای تعمیم علت یا تغییر خودکار پروفایل کافی نیست. گزینه‌های ردشده، توضیحات رقیب و نتایج ناموفق نیز باید حفظ شوند.
