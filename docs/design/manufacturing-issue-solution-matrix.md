# Manufacturing Issue–Solution Matrix (Domain Appendix)

> **Status:** Domain-specific appendix. This file is no longer the canonical enterprise-wide matrix. Use the [Enterprise Issue–Solution Reference Matrix](enterprise-issue-solution-reference-matrix.md) for full value-chain coverage, qualification rules, solution archetypes, typed relationships, user extensibility, governance and acceptance criteria.

This manufacturing-focused document is retained for traceability and detailed manufacturing examples. It must not be interpreted as limiting MANG_03 to manufacturing. Manufacturing-related issues often span materials, suppliers, engineering, production planning, operations, quality, maintenance, projects, logistics, finance, workforce, IT/data, EHS, governance and external disruption.

Governing principles: preserve intake; allow user-proposed Issue Types and Solution Types without code deployment; distinguish similarity from identity and causal relationships; keep qualification, urgency, priority, feasibility and authority separate; keep proposed rules/links unapproved until reviewed; preserve historical versions.
